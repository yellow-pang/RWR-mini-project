## 1. 전체 사용자 플로우

### 메인 플로우 다이어그램

```mermaid
flowchart TD
    Start([🏠 서비스 접속]) --> Main[메인 화면\n조건 선택]

    Main --> C1{거리 선택}
    C1 --> |1km / 3km / 5km| C2{소요 시간 선택}
    C2 --> |15분 / 30분 / 60분| C3{운동 유형 선택}
    C3 --> |걷기 / 조깅 / 러닝| Btn{추천 버튼 활성}

    Btn --> |클릭| Filter[조건 필터링\n+ 랜덤 추출]
    Filter --> |결과 있음| Result[추천 결과 화면\n코스 카드 표시]
    Filter --> |결과 없음| NoResult[결과 없음 안내\n다른 조건 제안]
    NoResult --> Main

    Result --> Q1{사용자 만족?}
    Q1 --> |만족| Q2{상세 보기?}
    Q1 --> |불만족| Again[다시 추천 버튼\n동일 조건 재추출]
    Again --> Result

    Q2 --> |예| Detail[코스 상세 화면\n설명 / 이유 / 주의 / 팁]
    Q2 --> |아니오| Q3{즐겨찾기 저장?}
    Detail --> Q3

    Q3 --> |예| Save[즐겨찾기 저장\nlocalStorage]
    Q3 --> |아니오| End([🏃 운동 시작!])
    Save --> End

    style Start fill:#e8f5e9
    style End fill:#e8f5e9
    style NoResult fill:#ffecb3
    style Filter fill:#e3f2fd
    style Save fill:#e3f2fd
```

### 서브 플로우: 즐겨찾기 관리

```mermaid
flowchart LR
    TabFav[즐겨찾기 탭] --> CheckFav{저장된 코스?}
    CheckFav --> |있음| FavList[즐겨찾기 목록]
    CheckFav --> |없음| EmptyFav[빈 상태 메시지\n코스를 저장해보세요]
    FavList --> FavCard[코스 카드]
    FavCard --> FavDetail[상세 보기]
    FavCard --> FavDelete[즐겨찾기 해제\n목록에서 즉시 제거]
```

### 서브 플로우: 최근 이력

```mermaid
flowchart LR
    TabHist[이력 탭] --> CheckHist{이력 존재?}
    CheckHist --> |있음| HistList[이력 목록\n최대 10개]
    CheckHist --> |없음| EmptyHist[빈 상태 메시지\n아직 추천 이력이 없어요]
    HistList --> HistCard[코스 카드 + 추천 시각]
    HistCard --> HistDetail[상세 보기]
```

## 2. 사용자 시나리오

### 시나리오 1 — 퇴근 후 가볍게 산책 (페르소나 A)

> 직장인 이산책 씨가 퇴근 후 30분 산책을 위해 RWR을 처음 사용하는 상황

```mermaid
sequenceDiagram
    actor 이산책
    participant 메인화면
    participant 추천엔진
    participant 결과화면
    participant localStorage

    이산책->>메인화면: 서비스 접속
    메인화면-->>이산책: 조건 선택 UI 표시

    이산책->>메인화면: 거리 3km 선택
    이산책->>메인화면: 소요 시간 30분 선택
    이산책->>메인화면: 운동 유형 걷기 선택
    메인화면-->>이산책: 추천 버튼 활성화

    이산책->>추천엔진: 추천 버튼 클릭
    추천엔진->>추천엔진: 조건 필터링 + 랜덤 추출
    추천엔진-->>결과화면: 코스 반환 (예: 서울숲 둘레길)

    결과화면-->>이산책: 코스 카드 표시
    이산책->>결과화면: 즐겨찾기 저장 클릭
    결과화면->>localStorage: 코스 ID 저장
    localStorage-->>결과화면: 저장 완료

    이산책->>결과화면: 상세 보기 클릭
    결과화면-->>이산책: 상세 정보 (설명/이유/주의/팁)
    이산책-->>이산책: 운동 시작! 🏃
```

**주요 포인트**

- 첫 사용에서 3번 클릭 + 버튼 1번으로 추천 완료
- 즐겨찾기 저장과 상세 보기를 동시에 활용
- 총 소요 시간: 30초 이내

---

### 시나리오 2 — 주말 러닝 코스 탐색 (페르소나 B)

> 박러닝 씨가 주말 아침 새로운 5km 러닝 코스를 찾는 상황

```mermaid
sequenceDiagram
    actor 박러닝
    participant 메인화면
    participant 추천엔진
    participant 결과화면

    박러닝->>메인화면: 서비스 접속
    박러닝->>메인화면: 거리 5km, 시간 60분, 러닝 선택
    박러닝->>추천엔진: 추천 요청

    추천엔진-->>결과화면: 코스 A 추천

    박러닝->>결과화면: 마음에 안 들어서 다시 추천
    결과화면->>추천엔진: 코스 A 제외 재추출
    추천엔진-->>결과화면: 코스 B 추천

    박러닝->>결과화면: 상세 보기
    결과화면-->>박러닝: 상세 정보 확인
    박러닝-->>박러닝: 만족 → 출발! 🏃
```

**주요 포인트**

- "다시 추천" 기능으로 처음 결과가 마음에 들지 않아도 자연스럽게 재탐색
- 상세 화면에서 코스 정보를 충분히 파악 후 결정

---

### 시나리오 3 — 매일 8,000보 걷기 목표 (페르소나 C)

> 최건강 씨가 매일 아침 1시간 걷기 목적지를 정하는 상황

```mermaid
sequenceDiagram
    actor 최건강
    participant 메인화면
    participant 결과화면
    participant 즐겨찾기화면
    participant localStorage

    최건강->>메인화면: 서비스 접속 (매일 아침)
    최건강->>메인화면: 거리 5km, 시간 60분, 걷기 선택
    메인화면-->>결과화면: 코스 추천

    최건강->>결과화면: 즐겨찾기 저장
    결과화면->>localStorage: 저장

    Note over 최건강, 즐겨찾기화면: 다음 날 방문
    최건강->>즐겨찾기화면: 즐겨찾기 탭 클릭
    즐겨찾기화면->>localStorage: 저장된 코스 불러오기
    localStorage-->>즐겨찾기화면: 코스 목록 반환
    즐겨찾기화면-->>최건강: 저장된 코스 목록 표시
    최건강-->>최건강: 저장된 코스로 출발! 🚶
```

**주요 포인트**

- 즐겨찾기 기능으로 매번 조건 선택 없이 바로 재사용 가능
- localStorage 영속성으로 새로고침·재방문 후에도 목록 유지

---

### 시나리오 4 — 이전에 갔던 코스 다시 보기

> 지난주 추천받은 코스가 좋았는데 어떤 코스였는지 확인하는 상황

```mermaid
sequenceDiagram
    actor 사용자
    participant 이력화면
    participant localStorage

    사용자->>이력화면: 최근 이력 탭 클릭
    이력화면->>localStorage: 이력 불러오기
    localStorage-->>이력화면: 최근 10개 코스 반환
    이력화면-->>사용자: 추천 일시 포함 목록 표시
    사용자->>이력화면: 이전 코스 상세 보기 클릭
    이력화면-->>사용자: 코스 상세 정보 표시
    사용자->>이력화면: 즐겨찾기에 저장
```

## 3. 예외 플로우

### 예외 케이스 정의

| #   | 상황                    | 처리 방법                                                                 | 사용자 경험                       |
| --- | ----------------------- | ------------------------------------------------------------------------- | --------------------------------- |
| E1  | 조건에 맞는 코스가 없음 | "조건에 맞는 코스가 없어요. 조건을 조금 바꿔보세요." 안내                 | 안내 메시지 + 조건 변경 유도      |
| E2  | 해당 조건 코스가 1개뿐  | 다시 추천 클릭 시 "현재 조건에 코스가 1개뿐이에요." 안내                  | 동일 코스 유지 + 안내 메시지      |
| E3  | localStorage 저장 실패  | try-catch 처리 + 조용한 실패 (서비스 중단 없음)                           | 기능 사용에 이상 없음             |
| E4  | 즐겨찾기가 비어 있음    | 빈 상태 UI: "아직 저장된 코스가 없어요. 마음에 드는 코스를 저장해보세요!" | 빈 상태 일러스트 + 메인 이동 링크 |
| E5  | 이력이 없음             | 빈 상태 UI: "아직 추천 이력이 없어요. 지금 바로 첫 코스를 찾아보세요!"    | 빈 상태 + 메인 이동 링크          |

### 예외 처리 플로우

```mermaid
flowchart TD
    A[추천 요청] --> B{조건에 맞는 코스 수}
    B --> |0개| C[빈 결과 상태\n안내 메시지 표시]
    B --> |1개| D[단일 코스 표시\n다시 추천 제한 안내]
    B --> |2개 이상| E[랜덤 추출 후 표시]
    C --> F[다른 조건으로 돌아가기]
    D --> G[즐겨찾기 저장 유도]
    E --> H[정상 결과 화면]
```

## 4. 화면 전환 다이어그램

### 화면 상태 전환 (State Diagram)

```mermaid
stateDiagram-v2
    [*] --> Main: 서비스 접속

    Main --> Result: 추천 버튼 클릭
    Result --> Main: 조건 변경
    Result --> Detail: 상세 보기
    Detail --> Result: 뒤로 가기

    Main --> Favorites: 즐겨찾기 탭
    Main --> History: 이력 탭
    Favorites --> Main: 홈 탭
    Favorites --> Detail: 코스 상세
    History --> Main: 홈 탭
    History --> Detail: 코스 상세

    Detail --> [*]: 운동 시작!

    state Main {
        [*] --> 조건미선택
        조건미선택 --> 일부선택: 조건 1~2개 선택
        일부선택 --> 전체선택: 마지막 조건 선택
        전체선택 --> 조건미선택: 초기화
    }

    state Result {
        [*] --> 결과표시
        결과표시 --> 즐겨찾기ON: 저장 클릭
        즐겨찾기ON --> 즐겨찾기OFF: 해제 클릭
    }
```

### 내비게이션 구조

```mermaid
graph TD
    Nav[하단 탭 바] --> T1[🏠 홈\n메인/결과 화면]
    Nav --> T2[❤️ 즐겨찾기\n저장된 코스]
    Nav --> T3[🕐 최근 이력\n최근 추천 목록]

    T1 --> Main[조건 선택 → 결과]
    T2 --> Fav[즐겨찾기 목록]
    T3 --> Hist[최근 10개 이력]

    Main --> Detail1[코스 상세]
    Fav --> Detail2[코스 상세]
    Hist --> Detail3[코스 상세]

    Detail1 & Detail2 & Detail3 --> Back[뒤로 가기\n이전 화면 복귀]
```
